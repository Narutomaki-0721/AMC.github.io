# 整数规划入门 · 怎样核对求解器的答案

安排车辆、人员或设备时，决策量常常只能取整数。Google OR-Tools 的教程给出了一个很小的例子，可以先手算，再运行官方 Python 示例核对建模是否正确。

目标是让 `x + 10y` 最大。两个变量均为非负整数，且满足 `x + 7y ≤ 17.5` 和 `x ≤ 3.5`。因此只需枚举三种可能的 `y`；对每种情况，增大可行的 `x` 都会改善目标。

| y | 最大可行 x | 目标值 |
| --- | --- | --- |
| 0 | 3 | 3 |
| 1 | 3 | 13 |
| 2 | 3 | 23 |

最优解是 `(3, 2)`，目标值为 23。把它代回第一条约束得到 17，还剩 0.5 的余量。这个余量不足以增加一个整数单位。

## 用在队内模型里

先把变量的对象和单位写清楚，再指定整数范围、资源约束和目标。求解后至少记录求解状态、目标值和各约束余量。遇到小规模数据时，可以用独立枚举检查代码是否漏掉约束。
