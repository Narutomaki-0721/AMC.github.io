# 上传文档

选择栏目，登录有仓库写权限的 GitHub 账号，拖入文件并提交到 `main`。部署完成后，同学从对应栏目打开文章即可在线阅读。

| 栏目 | 文件上传 |
| --- | --- |
| 赛程消息 | [上传赛事公告](https://github.com/Narutomaki-0721/AMC.github.io/upload/main/docs/schedule) |
| 历年赛题收集 | [上传赛题](https://github.com/Narutomaki-0721/AMC.github.io/upload/main/docs/problems) |
| 参考资料文档 | [上传参考资料](https://github.com/Narutomaki-0721/AMC.github.io/upload/main/docs/resources) |
| 笔记与练习 | [上传团队笔记](https://github.com/Narutomaki-0721/AMC.github.io/upload/main/docs/practice) |

支持 Markdown（`.md`）、Word（`.docx`）、文本 PDF 和 UTF-8 文本（`.txt`）。Markdown 第一行可写 `# 文章标题`。其他文档用文件名作标题，并附原文件链接，方便核对公式和图片。扫描 PDF 需先做 OCR。请上传可公开分享的文件。

要请 AI 收录，打开「问 AI」，说清资料主题、栏目和数量；指定网页时可直接附 HTTPS 链接。审批后系统读取来源并生成站内阅读笔记。对已在仓库 `content-policy.json` 登记的可转载原文，系统同时附上转换后的正文。
