# 2024 MCM C 题 · 网球比赛中的势头

这道题以 2023 年温网男单逐分数据为背景。题目给出的决赛标识是 `2023-wimbledon-1701`。读题时先区分两个问题：赛后怎样描述走势，以及站在某一分开始前，能否预判下一次变化。

## 题目要交付什么

| 任务 | 建模时需要回答的问题 |
| --- | --- |
| 描述走势 | 此时谁更占优？优势有多大？把逐分变化画出来。 |
| 检验随机性 | 已经考虑发球优势时，随机得分是否也会出现类似的连续得分？ |
| 预测转折 | 哪些在当前时刻已知的信息可以预示转折？换一场比赛后还有效吗？ |
| 给教练的建议 | 把分析转换成可执行的比赛建议，并说明适用范围。 |

## 从附件开始

先读 `data_dictionary.csv`，再打开 `Wimbledon_featured_matches.csv`。筛选一场比赛，检查盘、局、分的顺序；用 `server` 区分发球方，用 `point_victor` 确认该分的胜者。官方 PDF 末尾给了逐行解释，适合用来核对导入结果。

**队内练习**：任选一段连得分，标出发球方。用另外几场比赛估计发球得分率，再比较这段表现和基准之间的差异。若要预测下一分，应只使用发球前可见的特征，把该分的胜者留作验证标签。
